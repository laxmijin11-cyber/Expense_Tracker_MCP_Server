Here's a brief guide to **using FastMCP with `uv`** commands:

## 🎯 **What is FastMCP?**

FastMCP is a Python framework for building **MCP (Model Context Protocol) servers** quickly. It lets you expose tools, resources, and prompts to LLM clients like Claude Desktop.

---

## 📦 **Installation with UV**

| Command | Meaning |
|---------|---------|
| `uv add fastmcp` | Add FastMCP to project |
| `uv pip install fastmcp` | Install FastMCP directly |
| `uvx fastmcp` | Run FastMCP CLI without installing |
| `uv add "fastmcp[cli]"` | Install with CLI extras |

## 📝 **Minimal FastMCP Server Example**

**`server.py`:**
```python
from fastmcp import FastMCP

mcp = FastMCP("My Server")

@mcp.tool()
def add(a: int, b: int) -> int:
    """Add two numbers"""
    return a + b

@mcp.resource("greeting://{name}")
def get_greeting(name: str) -> str:
    """Get a personalized greeting"""
    return f"Hello, {name}!"

if __name__ == "__main__":
    mcp.run()
```

Here is a **brief cheat sheet** of the most common SQLite commands you will use in Python:

### 1. Basic Setup
```python
import sqlite3
conn = sqlite3.connect('database.db')
cursor = conn.cursor()
```

### 2. Create Table (CRUD - Create)
```python
cursor.execute("""
    CREATE TABLE IF NOT EXISTS users (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        name TEXT NOT NULL,
        age INTEGER,
        email TEXT UNIQUE
    )
""")
conn.commit()
```

### 3. Insert Data (CRUD - Create)
*Always use `?` to prevent SQL injection.*
```python
# Insert one row
cursor.execute("INSERT INTO users (name, age) VALUES (?, ?)", ("Alice", 25))

# Insert multiple rows
users = [("Bob", 30), ("Charlie", 22)]
cursor.executemany("INSERT INTO users (name, age) VALUES (?, ?)", users)

conn.commit()
```

### 4. Select Data (CRUD - Read)
```python
# Get all rows
cursor.execute("SELECT * FROM users")
rows = cursor.fetchall() # Returns a list of tuples

# Get one row
cursor.execute("SELECT * FROM users WHERE name = ?", ("Alice",))
row = cursor.fetchone() # Returns a single tuple

# Get data as dictionaries (like your FastMCP code!)
cursor.execute("SELECT * FROM users")
cols = [col[0] for col in cursor.description]
dict_rows = [dict(zip(cols, row)) for row in cursor.fetchall()]
```

### 5. Update Data (CRUD - Update)
```python
cursor.execute("UPDATE users SET age = ? WHERE name = ?", (26, "Alice"))
conn.commit()
```

### 6. Delete Data (CRUD - Delete)
```python
cursor.execute("DELETE FROM users WHERE name = ?", ("Charlie",))
conn.commit()
```

### 7. Useful Clauses
```python
# Filter & Sort
cursor.execute("SELECT * FROM users WHERE age > ? ORDER BY age DESC", (20,))

# Search using LIKE (wildcards)
cursor.execute("SELECT * FROM users WHERE name LIKE ?", ('%li%',)) # Finds Alice, Charlie
```

### 8. Safe Context Manager (Best Practice)
Your FastMCP code uses this. It automatically commits and closes the connection:
```python
with sqlite3.connect('database.db') as conn:
    conn.execute("INSERT INTO users (name) VALUES (?)", ("David",))
    # No need for conn.commit() or conn.close() here!
```

<!-- A connection can only hold the connection. A cursor is the worker that actually sends the SQL commands to the database and fetches the results. -->

Here is exactly what those 2 lines do:

### Line 1: `cols = [d[0] for d in cur.description]`
**Meaning:** "Grab the column names."
When you run a `SELECT` query, the database returns the data (rows) but also metadata about the columns. `cur.description` looks something like this:
`[('id', None, ...), ('date', None, ...), ('amount', None, ...)]`
This line loops through that and extracts just the first item (`d[0]`) from each tuple, resulting in a clean list: 
`['id', 'date', 'amount', 'category', 'subcategory', 'note']`

### Line 2: `return [dict(zip(cols, r)) for r in cur.fetchall()]`
**Meaning:** "Combine the column names with the data to make dictionaries."
- `cur.fetchall()` grabs all the data rows. It looks like this: `[(1, '2026-10-26', 50.0, 'Food'), (2, '...')]`
- `zip(cols, r)` pairs the names with the values for a single row. Example: `('id', 1), ('date', '2026-10-26')`
- `dict(...)` turns those pairs into a dictionary: `{'id': 1, 'date': '2026-10-26', ...}`
- The `for r in ...` loops through every row.

**Final Result:** A list of dictionaries like this (which is exactly what MCP needs to return JSON):
```json
[
  {"id": 1, "date": "2026-10-26", "amount": 50.0, "category": "Food"},
  {"id": 2, "date": "2026-10-26", "amount": 20.0, "category": "Travel"}
]
```
